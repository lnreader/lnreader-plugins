# Komga Plugin

[Komga](https://komga.org/) is a self-hosted media server. Unlike the other plugins, which scrape
a fixed public site, the Komga plugin connects to *your own* server, so it needs a bit of one-time
setup after installing.

1. Install the Komga plugin.
2. On the installed plugins page, press the cog icon to open the plugin settings.
3. Fill in the required information (email, password, and your Komga server URL).
4. Press save and restart the app.
5. The Komga plugin will now work like the other plugins.
